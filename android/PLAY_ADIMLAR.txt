Sanal Bahçe — Google Play adımları
=================================

Paket adı (değiştirme): com.batuhanklcky.sanalbahce
Web: https://batuhanklcky.github.io/sanalbahce/
Gizlilik URL (Console'a yapıştır): https://batuhanklcky.github.io/sanalbahce/gizlilik.html

1) Play Console
   - Yeni uygulama oluştur: Sanal Bahçe, ücretsiz, Oyun / Simülasyon
   - Play App Signing açık kalsın

2) Bu bilgisayarda AAB üret
   cd android
   export TWA_STORE_PASS='kendi-guclu-sifren'
   export TWA_KEY_PASS='kendi-guclu-sifren'
   ./build-aab.sh
   (İlk çalıştırmada Bubblewrap Android proje dosyalarını üretir; JDK + Android SDK ister.)
   Alternatif: npx @bubblewrap/cli init --manifest https://batuhanklcky.github.io/sanalbahce/manifest.json
   sonra bu klasördeki twa-manifest.json ile hizala.

3) Upload keystore'u yedekle
   android-upload.keystore + şifreleri güvenli yerde sakla. Repoya KOYMA.

4) AAB'yi Internal testing'e yükle
   Play Console → Testing → Internal testing → Create release → AAB yükle

5) App signing SHA-256
   Setup → App integrity → App signing key certificate → SHA-256 kopyala
   Repo kökünde .well-known/assetlinks.json içindeki
   REPLACE_WITH_PLAY_APP_SIGNING_SHA256 yerine yapıştır (iki nokta üst üste olmadan, büyük harf).
   main'e push et; birkaç dakika sonra şu adres 200 dönmeli:
   https://batuhanklcky.github.io/sanalbahce/.well-known/assetlinks.json

6) Store listing
   - Kısa / uzun açıklama (Türkçe)
   - İkon 512, feature graphic 1024x500, en az 2 telefon ekran görüntüsü
   - Gizlilik politikası URL'si (yukarıdaki)

7) App content formları
   - Data safety: Analitik (IP/user agent), yerel depolama; satış yok; HTTPS
   - Reklam: Hayır
   - Hedef kitle: 13+ (çocuklara özel değil)
   - İçerik derecelendirmesi anketini doldur

8) Internal test cihazında kontrol
   - Tam ekran TWA (üstte Chrome çubuğu OLMAMALI)
   - Kayıt, mağaza, sulama, hasat, hayvan, kelebek
   - Gizlilik linki istatistik panelinde açılıyor mu

9) Production'a gönder → inceleme

Data safety kısa cevaplar
------------------------
Toplanan: Cihaz veya diğer kimlikler (user agent), yaklaşık konum (IP, analitik)
Amaç: Analitik
Veri satışı: Hayır
Şifreleme (transit): Evet
Kullanıcı silebilir: Evet (talep / yerel veri silme)
